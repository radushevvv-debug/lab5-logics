# lab5-logics
Лабораторная работа №5: Определение характеристик графов. Язык: C. Задания: task1.c - генерация и вывод матрицы смежности неориентированного графа, определение количества рёбер, поиск изолированных, концевых и доминирующих вершин; task2.c - построение матрицы инцидентности, определение количества рёбер и поиск вершин тех же типов.
